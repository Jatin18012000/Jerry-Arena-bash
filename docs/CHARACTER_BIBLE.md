> Only the roster names and build order are decided. Fields marked _TBD_ are open and are to be
> defined in the character design phase. Nothing here should be treated as final lore.

## Character sheet template

Each fighter gets a sheet with these fields before modelling starts:

| Field | Description |
| --- | --- |
| Name | |
| Role / archetype | e.g. rushdown, grappler, zoner, all-rounder |
| Silhouette & palette | Must read clearly at fighting-game camera distance |
| Personality / backstory | Short; drives intro/win quotes and Story mode |
| Weapon / props | If any (modelled in `blender/weapons`) |
| Move list | Normals, specials, super — with frame data (see COMBAT_SYSTEM.md) |
| Animations required | Idle, walk, jump, crouch, block, hits, knockdown, getup, intro, win, KO |
| Home arena | |
